# Titanic-Survival-Prediction
Machine learning project predicting Titanic passenger survival using Logistic Regression and Decision Tree models.

The objective of this project is to learn the fundamentals of machine learning by completing a full ML workflow — from data loading to model evaluation.
The project also aims to understand the difference between supervised and unsupervised learning through hands-on practice using the Titanic dataset.

• Objectives:
Cleaned and preprocessed the Titanic dataset
Handled missing values and performed categorical encoding
Visualised passengers and survival trends using Seaborn and Matplotlib
Built the classification models (Logistic Regression, Decision Tree)
Applied unsupervised learning (K-Means clustering) for pattern discovery
Evaluated and compared model accuracy 

• Tools and Libraries Used:
Python
Pandas, NumPy
Matplotlib, Seaborn
Scikit-learn

 • Models Implemented:
 
| Model               | Type         | Accuracy                                                         |
| ------------------- | ------------ | ---------------------------------------------------------------- |
| Logistic Regression | Supervised   | 81%                                                              |
| Decision Tree       | Supervised   | 78%                                                              |
| K-Means             | Unsupervised | Clustered passengers into 3 groups based on Age, Fare, and Class |


• Key Insights
- Female passengers and higher-class travelers had higher survival rates.
- Age and Fare showed clustering patterns related to passenger class and survival probability.
- Logistic Regression performed slightly better than the Decision Tree in prediction accuracy.

• Dataset
Kaggle Titanic Dataset — https://www.kaggle.com/datasets/yasserh/titanic-dataset
